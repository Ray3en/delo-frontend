useState Занятие 02

useState хранит данные компонента

const [count, setCount] = useState(0);

function handleClick() {
  setCount(count + 1);
}
Как это работает

count содержит текущее число. setCount задаёт новое число, после чего React обновляет текст на экране.

Правила хуков Занятие 02

Порядок вызовов должен сохраняться

  • Вызывайте хуки на верхнем уровне компонента или собственного хука.
  • Не помещайте вызов хука в условие, цикл или вложенную функцию.
  • React связывает состояние с позицией вызова в дереве компонентов.
  • Функции, начинающиеся с use, могут объединять другие хуки.
// Плохо
if (isOpen) useEffect(() => {}, []);

// Хорошо
useEffect(() => {
  if (!isOpen) return;
}, [isOpen]);
Жизненный цикл Занятие 02

Компонент появляется, меняется и удаляется

Появился

React впервые показывает компонент на странице.

Изменился

Props или state изменились, поэтому React обновляет интерфейс.

Удалился

Компонент больше не нужен и исчезает со страницы.

Где нужен useEffect

useEffect запускает дополнительное действие после появления или изменения компонента.

Жизненный цикл · схема Занятие 02

Четыре этапа работы компонента

01 · Инициализация

React получает props, создаёт начальное state и впервые вызывает функцию компонента.

02 · Монтирование

React добавляет элементы компонента на страницу. После показа запускается useEffect.

03 · Обновление

Props или state изменились. React снова вызывает компонент и обновляет нужные элементы.

04 · Размонтирование

Компонент удаляется со страницы. React запускает функции очистки эффектов.

useEffect Занятие 02

useEffect запускает код после обновления экрана

useEffect(() => {
  console.log('Компонент показан или обновлён');
});
  • Сначала React показывает интерфейс.
  • После этого выполняется код внутри useEffect.
  • Массив зависимостей определяет, когда повторять эффект.
useEffect · без массива Занятие 02

Запуск после каждого обновления

useEffect(() => {
  console.log('Интерфейс обновился');
});
Когда срабатывает

Сообщение появляется после первого показа компонента и после каждого следующего обновления.

useEffect · пустой массив Занятие 02

Запуск при появлении компонента

useEffect(() => {
  console.log('Страница задач открыта');
}, []);
Пример применения

Можно один раз загрузить начальные данные или подключить обработчик события. Пустой массив означает, что эффект не зависит от props и state.

useEffect · зависимость Занятие 02

Запуск при изменении выбранного значения

useEffect(() => {
  document.title = `Задач: ${tasks.length}`;
}, [tasks.length]);
Пример применения

Эффект запускается при первом показе компонента и после изменения количества задач. Другие обновления его не запускают.

useRef Занятие 02

Значение между рендерами без нового рендера

const inputRef = useRef<HTMLInputElement>(null);

function focusInput() {
  inputRef.current?.focus();
}

<input ref={inputRef} />

Подходит

DOM-элемент, id таймера, предыдущее значение, объект внешней библиотеки.

Не подходит

Данные, изменение которых должно сразу обновить интерфейс. Для них нужен state.

useContext · пример Занятие 02

Тема доступна всем компонентам

type Theme = 'light' | 'dark';
const ThemeContext = createContext(null);

function App() {
  const [theme, setTheme] = useState<Theme>('light');
  const toggleTheme = () =>
    setTheme(value => value === 'light' ? 'dark' : 'light');

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      <Page />
    </ThemeContext.Provider>
  );
}
Что передаёт Context

Provider хранит текущую тему и функцию переключения. Любой вложенный компонент получает их через useContext без цепочки props.

Тема интерфейса Занятие 02

Стили светлой и тёмной темы

.theme-light {
  color: #111820;
  background-color: #f7f3eb;
}

.theme-dark {
  color: #f7f3eb;
  background-color: #111820;
}
Как применить

Добавляем к корневому блоку класс theme-light или theme-dark. Цвет текста и фон меняются вместе.

useContext · Header Занятие 02

Header переключает общую тему

function Header() {
  const context = useContext(ThemeContext);

  if (!context) return null;
  const { theme, toggleTheme } = context;

  return (
    <header className={`theme-${theme}`}>
      <h1>Task Tracker</h1>
      <label>
        <input
          type="checkbox" role="switch"
          checked={theme === 'dark'}
          onChange={toggleTheme}
        />
        Тёмная тема
      </label>
    </header>
  );
}
Связь примеров

Header читает theme и toggleTheme из ThemeContext. После переключения React меняет класс theme-light на theme-dark или обратно.

Оптимизация · пример Занятие 02

useMemo и useCallback после измерения

useMemo

Кеширует результат вычисления между рендерами.

const visible = useMemo(
  () => filterTasks(tasks, query),
  [tasks, query]
);

useCallback

Сохраняет ссылку на функцию, когда это важно для оптимизированного потомка.

const remove = useCallback(
  id => setTasks(v => v.filter(x => x.id !== id)),
  []
);
Оптимизация Занятие 02

Сначала находим медленное место

  • Откройте React DevTools Profiler и повторите медленное действие.
  • Проверьте, какие компоненты обновились и сколько времени занял рендер.
  • Уберите лишние эффекты и ненужные обновления состояния.
  • Используйте useMemo или useCallback только для найденной проблемы.
Главное правило

Если интерфейс работает быстро, дополнительная мемоизация не нужна.

HTTP и Fetch API Занятие 02

GET-запрос возвращает Response

const response = await fetch(url);

if (!response.ok) {
  throw new Error(`HTTP ${response.status}`);
}

const data = await response.json();
Важно

fetch не отклоняет Promise только из-за статуса 404 или 500. Успешность HTTP-ответа проверяем через response.ok.

Состояния запроса Занятие 02

Интерфейс показывает процесс

Loading

Запрос выполняется. Показываем индикатор и исключаем повторный запуск.

Error

Объясняем проблему и даём повторить запрос.

Success

Показываем данные или понятное пустое состояние.

const [status, setStatus] = useState<'idle' | 'loading' | 'success' | 'error'>('idle');
Практика · данные Занятие 02

Запрос отдельно от компонента

type ApiTodo = {
  id: number;
  title: string;
  completed: boolean;
};

async function fetchTodos() {
  const response = await fetch(
    'https://jsonplaceholder.typicode.com/todos?userId=1'
  );

  if (!response.ok) {
    throw new Error(`HTTP ${response.status}`);
  }

  return (await response.json()) as ApiTodo[];
}
Практика · эффект Занятие 02

Загружаем задачи при открытии страницы

useEffect(() => {
  async function load() {
    setStatus('loading');

    try {
      const items = await fetchTodos();
      setTasks(items);
      setStatus('success');
    } catch {
      setStatus('error');
    }
  }

  load();
}, []);
